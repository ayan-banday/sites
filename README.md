# sites

Public pages, served by GitHub Pages at https://ayan-banday.github.io/sites/

- `carrying-the-tvs-way/`: Carrying the TVS Way, JAIN University's page for TVS Institute for Quality and Leadership, laid out for laptops and phones.
- `udyaan-student-onboarding/`: Udyaan Student Onboarding, a horizontal presenter deck of the 14-day student onboarding plan.
- `selling-without-stock/`: Selling Without Stock, a horizontal-scroll class presentation on dropshipping.
- `the-range/`: The Range, a horizontal scroll painting of eight mountains.

Each page is one self-contained HTML file. No database, no server, no tracking.
