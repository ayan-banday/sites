# sites

Public pages, served by GitHub Pages at https://ayan-banday.github.io/sites/

- `udyaan-14-days/`: Updated 14-Day Onboarding Plan for Udyaan, a tear-off wall calendar for the team: one page per phase, tap to tear.
- `udyaan-14-days/plain/`: Udyaan 14 Days, the earlier plain phone page (simplified onboarding and the incentive test). Add #edit to the link to edit it in the browser.
- `reliability-before-speed/`: Reliability Before Speed, an 18-sheet class presentation on business ethics from an interview with founder Mario Ronci (arrow keys on a laptop, one scrolling page on a phone).
- `how-fuji-works/`: How Fuji Works, a phone-first page on how Ash's life system routes reflections, moves tickets and runs at night.
- `carrying-the-tvs-way/`: Carrying the TVS Way, JAIN University's page for TVS Institute for Quality and Leadership, laid out for laptops and phones.
- `udyaan-student-onboarding/`: Udyaan Student Onboarding, a horizontal presenter deck of the 14-day student onboarding plan.
- `selling-without-stock/`: Selling Without Stock, a horizontal-scroll class presentation on dropshipping.
- `the-range/`: The Range, a horizontal scroll painting of eight mountains.
- `bhonpu-boss/`: BHONPU BOSS: Dialogue Maar!, a phone-sideways game about Situational Leadership, where every word you say through a truck-art megaphone becomes a solid object.

Each page is one self-contained HTML file. No database, no server, no tracking.
